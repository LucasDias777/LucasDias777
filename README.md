<h3 align="center">🚀 Projetos em destaque</h3>

- 🚚 **[Amazonas Transportes — Site institucional](https://www.amazonastransportes.com.br/)** — Website institucional com **simulador de frete** que calcula rotas e distâncias em tempo real e envia a cotação por WhatsApp, com páginas de design moderno e backend em PHP para os formulários.

- ⛽ **[FuelTrack](https://fueltrack-sistema.web.app/)** — Sistema web para gestão de abastecimentos, frota, tanques, pneus, estoque, permissões de usuários, notificações e relatórios operacionais.

- 📦 **[Guelgi](https://guelgi.web.app/)** — Sistema de gestão de pedidos e entregas para transportadora: clientes, produtos, pedidos, financeiro e operações internas.

- 🌟 **[Nação de Talentos](https://nacaodetalentos.com.br/)** _(em construção)_ — Site institucional e sistema web para **gestão de estágios**, que auxilia no controle, na organização e no acompanhamento da documentação e dos contratos de estágio. Meu maior projeto até o momento.

- 🤖 **Andon BOT** — Automação de WhatsApp com painel web e **agente de atendimento por IA**: responde clientes, calcula frete em tempo real, gera comprovante em PDF com o mapa do trajeto e encaminha ao atendente, com fallback entre múltiplos provedores de IA.

- 💰 **Mensury** — Sistema de controle financeiro pessoal mensal: salário, gastos, metas e dashboard.

- 🏋️ **StriveFlow** — Cadastro e controle de treinos para professores e alunos, com relatórios em PDF/Excel e gráficos dinâmicos (Projeto de Conclusão de Curso).
